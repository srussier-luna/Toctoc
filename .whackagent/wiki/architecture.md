# Architecture

- App shown as **Toctoc** (`Toctoc.app`); target, module, bundle id `com.srussier.Clippy`, URL scheme `clippy` keep the old name. macOS 26 agent app (`LSUIElement`: no Dock icon) with a menu bar item (door icon, `MenuBarExtra`). Swift 6, SwiftUI views in AppKit `NSPanel`s.
- Project generated by XcodeGen: edit `project.yml`, run `xcodegen generate`. `Clippy.xcodeproj` and `Clippy/Info.plist` are generated, never edited.
- Targets: `Clippy` (app), `ClippyTests` (Swift Testing, hosted in the app).
- SwiftLint strict through the `SwiftLintPlugins` build tool plugin. CLI builds pass `-skipPackagePluginValidation`.

## Path of an event

`Claude hook` → `Scripts/clippy-hook.sh` → `open -g clippy://event?…` → `AppDelegate.application(_:open:)` → `ClippyEvent(url:)` → `SessionStore.handle(_:)` → `ClippyView` / `BubbleStackView` redraw.

## Folders

| Folder | Holds |
|---|---|
| `Clippy/Core/Claude` | `ClaudeApplication`: activation; `ClaudeSessionLinkFinder` |
| `Clippy/Core/Events` | `ClippyEvent`, `ClippyEvent.Kind` |
| `Clippy/Core/Stores` | `SessionStore`, `CharacterStore` + `CharacterStorage`, `OnboardingStore` + `OnboardingStorage`; models `Mood`, `Session`, `Bubble`, `CharacterKind`, `AccessoryKind`, `OnboardingStep` |
| `Clippy/Core/Overlay` | `ClippyOverlay`, `NSPanel.overlay(…)`, `FirstClickHostingView`, `ClippyPositionStorage`; placement math in `Models/` |
| `Clippy/UI/Views/Clippy` | `ClippyView`, `BubbleStackView`, `BubbleView` |
| `Clippy/UI/Views/Characters` | `CharacterView` + one folder per character, shared eyes (`EyeView`, `EyeStyle`) |
| `Clippy/UI/Views/Accessories` | accessory drawings, placement in `Models/` |
| `Clippy/UI/Views/CharacterMenu`, `Clippy/UI/Components` | menu bar menu, `AccessoryMenu`, `QuitButton` |
| `Clippy/UI/Modifiers` | mood motion, look around, blink |
| `Clippy/UI/Extensions` | `Path.addTurn(to:bulge:)` |
| `Scripts` | `clippy-hook.sh` |

## House rules

- Literal constants → `private extension Constants` at file end. `Constants` = empty namespace enum.
- No logic in enums: logic in structs (`EyeStyle`, `Bubble`, `ClippyEvent`).
- No comment in code except `// MARK:` / `// TODO:`.
- Header: `Created by Salomé Russier on DD/MM/YYYY.`

## Runtime check

- Install: copy the built `Toctoc.app` to `/Applications`, `lsregister -f` it, `lsregister -u` DerivedData and test-products copies. Else `open` may launch a stale copy.
- Fake event: `printf '{"hook_event_name":"Stop","session_id":"s","cwd":"/x/Demo"}' | Scripts/clippy-hook.sh`.
- Logs: `/usr/bin/log stream --level info --predicate 'subsystem == "com.srussier.Clippy"'`. Plain `log` = zsh builtin.
